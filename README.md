# Portfolio

A personal portfolio site built with React, TypeScript, TanStack Start, and Tailwind CSS.

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Stack

- [TanStack Start](https://tanstack.com/start/)
- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
